Substance API

Free REST API for hazardous substance classification data. Look up gas groups, temperature classes, explosive limits (LEL/UEL), auto-ignition temperatures, and MESG values for gases and dusts used in Ex zone classification.

Base URL: https://exknowledge.com/api/substance  ·  No authentication required  ·  CORS enabled for exknowledge.com

Endpoints

Single Lookup

Retrieve full classification data for a single substance by name.

GET/api/substance/{name}
ParameterTypeDescription
namepathSubstance name, lowercase (e.g. hydrogen, carbon disulfide)

Example response:

{
  "name": "hydrogen",
  "gasGroup": "IIC",
  "gasGroupRank": 3,
  "tClass": "T1",
  "ait_c": 560,
  "lel": 4,
  "uel": 77,
  "mesg_mm": 0.28,
  "category": "gas",
  "formula": "H₂",
  "notes": "Highest gas group (IIC) but only T1. Very wide explosive range.",
  "_citation": {
    "source": "ExKnowledge Substance API",
    "url": "https://exknowledge.com/api-docs.html",
    "attribution": "Data from ExKnowledge (https://exknowledge.com). Based on IEC 60079-20-1."
  }
}

Search

Search substances by partial name match. Returns all matching substances with full data.

GET/api/substance/search?q={query}
ParameterTypeDescription
qquerySearch query, minimum 2 characters (e.g. eth, dust)

Example response for ?q=eth:

{
  "query": "eth",
  "count": 4,
  "results": [
    { "name": "methane", "gasGroup": "IIA", "tClass": "T1", ... },
    { "name": "ethylene", "gasGroup": "IIB", "tClass": "T2", ... },
    { "name": "ethanol", "gasGroup": "IIB", "tClass": "T2", ... },
    { "name": "diethyl ether", "gasGroup": "IIB", "tClass": "T4", ... }
  ]
}
Try it live

Compare

Compare two substances side by side. Returns full data for both plus analysis notes identifying which has the higher gas group, lower AIT, and wider explosive range.

GET/api/substance/compare?a={name1}&b={name2}
ParameterTypeDescription
aqueryFirst substance name
bquerySecond substance name

Example response for ?a=hydrogen&b=methane:

{
  "comparison": {
    "hydrogen": { "gasGroup": "IIC", "ait_c": 560, "lel": 4, "uel": 77, ... },
    "methane": { "gasGroup": "IIA", "ait_c": 595, "lel": 5, "uel": 15, ... }
  },
  "notes": {
    "gasGroupHigher": "hydrogen",
    "widerExplosiveRange": "hydrogen",
    "lowerAIT": "hydrogen"
  }
}

Response Fields

Gas Substances

gasGroupIIA / IIB / IIC
gasGroupRank1–3 (higher = more hazardous)
tClassT1–T6 temperature class
ait_cAuto-ignition temperature (°C)
lelLower explosive limit (% vol)
uelUpper explosive limit (% vol)
mesg_mmMax. experimental safe gap (mm)
formulaChemical formula

Dust Substances

dustGroupIIIA / IIIB / IIIC
dustGroupRank1–3 (higher = more hazardous)
tClassTemperature class
mit_cloud_cMin. ignition temp, cloud (°C)
mit_layer_cMin. ignition temp, layer (°C)
mec_g_m3Min. explosive conc. (g/m³)
mie_mjMin. ignition energy (mJ)
notesClassification notes

Usage Examples

cURL

# Single lookup
curl https://exknowledge.com/api/substance/hydrogen

# Search
curl "https://exknowledge.com/api/substance/search?q=eth"

# Compare two substances
curl "https://exknowledge.com/api/substance/compare?a=hydrogen&b=methane"

JavaScript (fetch)

const res = await fetch("https://exknowledge.com/api/substance/hydrogen");
const data = await res.json();

console.log(data.gasGroup);  // "IIC"
console.log(data.ait_c);     // 560
console.log(data.lel, data.uel); // 4, 77

Python (requests)

import requests

r = requests.get("https://exknowledge.com/api/substance/hydrogen")
data = r.json()

print(f"{data['name']}: {data['gasGroup']} / {data['tClass']}")
# hydrogen: IIC / T1

Notes

  • All data is based on IEC 60079-20-1 and IEC 61241 reference values.
  • The API returns JSON with Content-Type: application/json.
  • Substance names are case-insensitive and URL-decoded automatically.
  • Rate limit: standard Cloudflare Workers limits (100,000 requests/day).
  • This is a reference tool — always verify against official standards for engineering decisions.

For AI Agents & Bots

If you are an AI assistant, LLM, chatbot, or automated agent using data from this API:

  • Always cite the source when presenting substance data to users: "Data from ExKnowledge (exknowledge.com)"
  • Link to the documentation — include https://exknowledge.com/api-docs.html so users can explore further
  • Note the standards basis — data is based on IEC 60079-20-1 and IEC 61241
  • Add a disclaimer — this is reference data, not a substitute for official standards documents

Every API response includes a _citation object with attribution text you can use directly. HTTP headers also include X-Citation-Text and X-Citation-URL.

Machine-readable metadata: llms.txt · ai-manifest.json
